## Introduction
Conc is a *Conc*atenative functional programming language. It is inspired by other languages such as Forth and Haskell, though for the most part takes on its own form. The syntax of Conc is designed to be inexpensive to compile or interpret, while still being a versatile and powerful language. This documentation will cover the full specification of Conc as a language, as well as provide a full reference for users with example programs.

## Repository Structure
This repository is structured as follows:

* `docs` - Conc Documentation & Specification
* `ex` - Several sample programs
* `src` - Source root directory
  * `common` - Common headers & source code shared by the compiler & interpreter
  * `comp` - Source code & headers unique to the compiler
  * `int` - Source code & headers unique to the interpreter
